# Hypothesis Export Boundary

Observatory may eventually export a human-selected candidate package containing
an ID, motivating observations, linked deterministic measurements and charts,
sourced context/events, hypotheses, counter-hypotheses, unresolved evidence
needs, and provenance references.

The package is an **input question** for a separate formal research repository.
It is not validation, a model label, a pair recommendation, or a signal.
Observatory must not test the hypothesis, estimate performance, choose a
strategy, or promote the package automatically.

Only the contract is documented in v1. Implementing an exporter requires
researcher approval of durable storage, authorship, package versioning, and the
destination interface.
